### 🔭 What I Build

- 🖋️ **[OpenInkBridge](https://github.com/GoVed/OpenInkBridge)** — Open-source SDK & protocol for near-zero latency stylus drawing on E-Ink hardware (Onyx Boox) across Android Native, Web/WebView, and Linux.
- 🌐 **Grand Sim Pro** — GPU-accelerated survival and traffic simulation engine built in **Rust**, **wgpu** compute shaders, and WebAssembly with Hebbian learning agents.
- 🪐 **AR Gravity Simulator** — Augmented reality N-body solar system physics simulation (live on Google Play).
- ⚡ **[resim](https://github.com/GoVed/resim)** & **[gravitySim](https://github.com/GoVed/gravitySim)** — Physics and systems simulation experiments in **Rust** and **Python**.
